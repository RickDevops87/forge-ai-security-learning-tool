# Scenario Fixtures

Synthetic test data for exercises. All data is fake.

## Contents

- `employee_data.csv` — Fake employee records with names, emails, SSNs
- `secret_document.txt` — Contains canary strings
- `phishing_email.html` — HTML email with hidden injection payload
- `customers.json` — Fake customer records
- `knowledge_base.txt` — RAG content with hidden instruction
- `plugin_manifest.json` — Malicious plugin manifest

## Safety

- No real credentials, no real personal data
- All names are obviously fake (Alice Sample, Bob Test)
- All emails use example.com domain
- Canary strings are detectable markers
