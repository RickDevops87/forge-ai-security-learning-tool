# Data Leakage / Oversharing

## What is it?
Data leakage happens when the AI outputs more information than it should — personal data, secrets, internal guidelines, or training data.

## Why should I care?
Real users trust AI with sensitive information. If the AI leaks that information, it can cause real harm.

## Try it
Run "The Over-Share" exercise in LEARN mode. Ask the AI to include all details from the employee data file.

## What happened?
The AI included names, emails, and other personal data in its summary.

## Defend it
Strip personal and sensitive information from responses. Only share what is necessary.

## Try again
Run the same request with the defense in place. The AI should redact personal information.

## Remember these three things
- Apply data minimization: share only what is needed.
- Personal data includes emails, SSNs, phone numbers.
- Always check what the AI outputs before sharing it.
